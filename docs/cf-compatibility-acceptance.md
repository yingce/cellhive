## 本轮边界

- `cpuMs`：接受、校验、持久化并在版本读回中保留；stock workerd 阶段不声称执行 CPU 限额，也不以容器 CPU quota 代替。强制执行与 `exceededCpu` 验收留给后续 workerd 能力阶段。
- Cron：允许多个节点计算同一 UTC slot，但只有当前 cell owner session 物化和派发；cell 内 token 去重只在单 owner 下有效。派发成功但 fired 持久确认前崩溃可能重投；该至少一次窗口要求业务 occurrence 幂等。
- Workflow：现有创建事务已写入待派发 wake 和创建时目标版本。本轮以杀进程、lease 过期、升级后恢复的真实证据判定是否仍需修复。
- 桶：启动时已有条件创建、CAS、范围读、条件删除探针。本轮还要分别验证真实桶、follower fsync、epoch fence 和备份恢复；桶探针通过不能替代跨节点恢复验收。
