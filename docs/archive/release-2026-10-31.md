## 改动

### 数据/恢复
- `restore.ApplyFile`：先写同目录 temp、`Sync`、`Rename`，失败不会在 dest 留下半成品 DB；
  旧 `-wal/-shm` 在新镜像 durable 后、rename 前移除。
- paged cache：有效 dirty marker 或有效 marker 但拿不到 page source 时 `ErrPagedCacheUnusable`；
  `LatestEpoch`/`NewPageFetcher` 的真实错误向上传播；`removeCellFileSet` 先删数据文件，失败保留 marker。
- workflow：`Prune` select+delete 同事务并复核状态；`PruneRetention` 每批 500、单次最多 20 批；
  新增 `instances(status, updated_ms)` 索引，零 retention binding 跳过扫描。
- objgc：删除前用 `GCRefs.IsReferenced` 点查；新增 `version_bundle_refs` / `versions.assets_sha` 查询。
- owner：`nextEpoch` 在 `owner-gen` 缺失时接受被替换记录的 epoch floor；node-lease 记录每 30 分钟最多
  `Touch` 一次以留在当前 segmented window；removed `owner-gen` 场景的 legacy epoch 复用已收窄。
- invocation：只删除被 prune 的 invocation 的 membership，去掉每次 Put/Start 的全表 anti-join。
- control：`resource_cleanups` 增加 due 索引、清理 7 天前的 completed job；app/worker purge 连带删除
  `deployment_events`。

### 热路径
- queue：dispatch 成功集合一次 `AckMany` + 一次 durable commit；`messages_claim(visible_at_ms,id)` 取代
  `messages_visible`，claim 不再临时排序。
- R2：conditional PUT 用 `Stat`/HEAD 取 ETag；multipart abort 只有 part 全部删除后才删 creation marker；
  写后 metadata 用 `GetMetaForVersion`，不再二次 HEAD。
- server：`Handler`/`AdminHandler` 只构建一次 mux；projection rebuild singleflight；KV TTL 已有 timer
  覆盖时走锁外快速路径。
- user-runtime loader：`latestVersionByFamily` 只在新版本出现时扫描 residents；`retiringCount` 取代每请求
  数组分配，sweep 用 O(1) 判断。
- ingress/hybrid：每 host 计数器上限 4096；hybrid 清理不在当前 snapshot 且窗口过期的 `lastSnapshot`。
- segmented authority：当前窗口缺失时先点读 h+1/h-1/h-2，再 List；`Touch` 支持 node-lease 保活。
- control `HostView`：projection 构建 host/worker 索引，按 host O(该 host 路由数) 取 view。
